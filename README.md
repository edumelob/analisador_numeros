# 📊 Analisador de Números

Um programa em Python que analisa uma lista de números, mostrando estatísticas básicas e gerando gráficos.

## 🚀 Funcionalidades
- Calcula soma, média, maior e menor valor
- Mostra a quantidade de números informados
- Gera gráfico de barras dos valores
- Salva os resultados em `.txt`
